# MCP Atlassian VS Code Extension

This extension provides commands to start and stop the local MCP server from VS Code, plus quick access to the health endpoint.

## Commands
- `MCP Atlassian: Start Server`
- `MCP Atlassian: Stop Server`
- `MCP Atlassian: Open Health Endpoint`
- `MCP Atlassian: Copy Server Endpoint`

## Settings
- `mcpAtlassian.serverUrl`: The server URL for the MCP endpoint (default `http://localhost:3000`).
- `mcpAtlassian.autoStart`: Automatically start the server when the extension activates.

## Usage
1. Open this folder in VS Code.
2. Run the commands from the Command Palette.
3. Use `http://localhost:3000` as the endpoint for other tools.
